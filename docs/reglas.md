# Reglas

Al entrar a Wolfland Network aceptas todas las reglas de esta página. Desconocerlas no te exime de cumplirlas.

!!! note "Para el administrador"
    Estas reglas son una base. Edítalas, bórralas o añade las tuyas según cómo quieras que funcione el servidor.

## 1. Reglas generales

1. **Respeto ante todo.** No se toleran insultos, acoso, discriminación ni amenazas hacia ningún jugador o miembro del staff.
2. **Una persona, una cuenta principal.** Evita usar cuentas alternas para obtener ventajas.
3. **Sigue las indicaciones del staff.** Sus decisiones deben respetarse; si no estás de acuerdo, reclama por los canales oficiales (nuestro [Discord](https://discord.com/invite/jCmngqZRFV)) y no en el chat.
4. **No compartas datos personales** tuyos ni de otras personas.
5. **Prohibido suplantar** a jugadores o miembros del staff.

## 2. Chat

1. Nada de **spam**, flood ni mensajes repetidos.
2. Evita escribir todo en **MAYÚSCULAS**.
3. Prohibida la **publicidad** de otros servidores, canales o tiendas.
4. No se permiten **contenidos ofensivos, +18 ni políticos** en el chat público.
5. Usa el idioma principal del servidor en el chat global.

## 3. Jugabilidad

1. **Prohibidos los hacks y mods con ventaja:** x-ray, killaura, fly, auto-clickers, etc.
2. **Prohibido abusar de bugs o exploits.** Si encuentras uno, repórtalo al staff.
3. **Sin granjas o máquinas que causen lag** de forma abusiva.
4. **Prohibido el AFK abusivo** con macros o programas para evitar el kick.
5. **Está prohibido duplicar ítems** o cualquier método de duplicación.

## 4. Construcción y protecciones

1. **No hagas griefing:** destruir, modificar o robar construcciones ajenas está prohibido.
2. **Respeta las protecciones** de otros jugadores y nunca intentes saltártelas.
3. **No construyas** de forma que ofenda, bloquee zonas importantes o afecte el rendimiento.
4. **Mantén tus zonas ordenadas.** El staff puede retirar construcciones abandonadas o problemáticas.

## 5. Jugadores de Bedrock

1. Las mismas reglas se aplican a **Java y Bedrock** por igual.
2. Está prohibido usar clientes modificados o herramientas externas para obtener ventaja, en cualquier edición.

## 6. Sanciones

| Gravedad | Ejemplos | Sanción |
|----------|----------|---------|
| Leve | Spam, mayúsculas, lenguaje inapropiado | Advertencia o silencio |
| Media | Insultos, publicidad, abuso de bugs | Silencio largo o expulsión temporal |
| Grave | Hacks, griefing, duplicación, acoso | Baneo temporal o permanente |

!!! warning "Reincidencia"
    Repetir una falta aumenta la sanción. El staff puede aplicar una sanción mayor según la gravedad del caso.

## 7. Apelaciones

Si crees que una sanción fue injusta, abre un [ticket en nuestro Discord](https://discord.com/invite/jCmngqZRFV) con tu nombre de usuario, la sanción recibida y tu explicación.
