# Cómo unirse

| Dato | Valor |
|------|-------|
| IP Java | `play.tuserver.com` |
| IP Bedrock | `play.tuserver.com` (puerto `19132`) |
| Versión | 1.21.x |

## Pasos

1. Abre Minecraft con la versión indicada.
2. Ve a **Multijugador → Añadir servidor**.
3. Pega la IP y pulsa **Listo**.
4. Entra y sigue las instrucciones del spawn.

!!! info "¿Problemas para entrar?"
    Pregunta en nuestro Discord y el staff te ayudará.
