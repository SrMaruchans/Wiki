# Servicios de contenido

¿Eres creador de contenido profesional y quieres ofrecer tus servicios a **Wolfland Network**? Aquí puedes proponer la creación de contenido promocional del servidor.

[:fontawesome-brands-discord: Abrir ticket](https://discord.com/invite/jCmngqZRFV){ .md-button .md-button--primary }

---

## Servicios

| Servicio | Descripción |
|----------|-------------|
| **Videos promocionales** | Videos para dar a conocer el servidor |
| **Reels** | Contenido corto para redes sociales |
| **Lives** | Transmisiones en vivo del servidor |
| **Transmisiones** | Streams con contenido del servidor |
| **Anuncios** | Piezas publicitarias del servidor |
| **Otros** | Otro contenido promocional (consúltalo por ticket) |

---

## Requisitos

!!! warning "Solo para creadores profesionales"
    Este servicio es **únicamente para personas que se dedican a la creación de contenido**. No es para quien está empezando.

Debes cumplir **todo** lo siguiente:

| Requisito | Detalle |
|-----------|---------|
| **Dedicación** | Dedicarte a la creación de contenido |
| **Seguidores** | **Más de 2k seguidores** en tus cuentas |
| **Alcance** | Un alcance **muy alto** en tus contenidos |

---

## Cómo solicitar

1. Abre un **ticket** en nuestro [Discord](https://discord.com/invite/jCmngqZRFV).
2. Indica **qué servicio** quieres ofrecer.
3. Comparte los enlaces a tus **cuentas** y a trabajos anteriores.
4. Muestra tus **métricas de alcance**.

!!! info "Colaboraciones remuneradas"
    Cualquier colaboración con pago se formaliza mediante un **contrato directo bajo términos y condiciones**. Son excepciones, no está disponible para cualquiera.

!!! tip "¿Solo quieres un rango?"
    Si lo que buscas es un rango por tu contenido del servidor, revisa [Rangos Media](rangos-media.md).
